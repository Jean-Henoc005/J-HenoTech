# J-HenoTech · Portfolio de Jhenoc Akpa

Portfolio personnel et vitrine de mes services HenoTech. Je suis étudiant en 1re année de BTS CIEL (Cybersécurité, Informatique et Réseaux, Électronique).

Le site mélange mes quatre activités : le dessin, la réparation et la maintenance, la création de sites web et la batterie.

## Pages

| Page | Contenu |
|---|---|
| `index.html` | Accueil : présentation, zone de dessin, pads de batterie jouables, aperçu des projets |
| `cv.html` | Mon CV en ligne, à télécharger ou à imprimer |
| `services.html` | Mes services (sites vitrines, installation Windows) et leurs tarifs |
| `disponibilites.html` | Mes horaires, avec mon statut de disponibilité en direct (heure de Paris) |
| `projets.html` | Kit convertisseur DCB 7 segments, affiches GWC Musique, ce portfolio |
| `mentions-legales.html`, `confidentialite.html` | Informations légales |

## Fonctionnalités

- Barre de navigation en bas de l'écran, utilisable sur téléphone, tablette et ordinateur
- Mode papier et mode plan bleu (nuit), mémorisés dans le navigateur
- Zone de dessin à la souris ou au doigt
- Pads de batterie jouables (touches Q, S, D, F), sons générés avec Web Audio
- Galeries d'images avec agrandissement
- Version imprimable du CV

## Technologies

HTML, CSS et JavaScript, sans framework ni dépendance. Aucun cookie, aucun traceur.

## Lancer le site

Téléchargez le dépôt, puis ouvrez `index.html` dans un navigateur. Gardez `style.css`, `script.js` et le dossier `images/` à côté des pages.
